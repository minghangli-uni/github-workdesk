# Contributing

Thanks for considering a contribution to GitHub Workdesk.

1. Check existing issues and the [roadmap](ROADMAP.md) before proposing a large feature.
2. Keep GitHub interactions read-only by default and preserve local notes across synchronization.
3. Use fictional data in tests, screenshots, logs, and examples. Never commit GitHub tokens, local databases, or private repository metadata.
4. Run `python3 -m unittest discover -s tests -v` before submitting a PR.
5. Write your issue/PR description in English and explain the change, test coverage, and any new permissions.

The core app uses the Python standard library and vanilla JavaScript, with no required build step. Prefer keeping the local install straightforward.
