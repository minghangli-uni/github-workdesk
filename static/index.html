GITHUB CONNECTION

Sync preferences

Sync reads your GitHub activity and never writes back to GitHub. Authentication is handled locally through gh auth login or a token in your environment.

STAY UP TO DATE

Notifications

Check for activity involving you while Workdesk is running. The first check quietly imports your existing unread inbox; new activity then triggers alerts.

GitHub may require a longer interval. On macOS, allow notifications from Script Editor / osascript in System Settings. Background checks use your gh auth login credentials.

APPEARANCE

Theme

Choose a familiar developer palette. Your preference is saved in this browser and works without GitHub access.

AUTOMATION

Daily reminder

On macOS, a LaunchAgent can refresh your work every day and show a system notification, even if this webpage isn't open (while logged in).

LOCAL DATA

Export & backup

Tasks, GitHub snapshots, notes, and historical events are stored in SQLite. Export anytime; no application data is sent to a Workdesk server.
